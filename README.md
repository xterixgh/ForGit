# ForGit

Приложение Avalonia с авторизацией, регистрацией и CRUD ролей.

## Запуск

Нужны .NET 10 и PostgreSQL с базой ForGit. Подключение настраивается в `ForGit/Data/AppDbContext.cs`. Примените существующие миграции через EF Core, затем выполните:

```sh
dotnet run --project ForGit/ForGit.csproj
```

После входа откройте «Роли». Выберите роль для редактирования, измените название и нажмите «Сохранить». Для создания нажмите «Новая роль», введите название и сохраните. Удаление требует подтверждения. Стандартную роль «Пользователь» нельзя переименовать или удалить; роли, назначенные пользователям, нельзя удалить.

Архитектура соответствует окнам входа и регистрации: `Views/RolesWindow.axaml` и обработчики в code-behind вызывают `Services/RoleService`, который работает с существующей моделью `Roles` через `AppDbContext`. Дополнительные миграции не требуются. Как и главное окно, CRUD доступен после входа; разграничение доступа по ролям не добавлено.
